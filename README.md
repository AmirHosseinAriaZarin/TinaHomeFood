# 🏭 Tina - Home Food Management System

A Spring Boot + React application for managing home food business,
including raw materials, products, and production workflows.

---

## 🚀 Tech Stack

| Layer | Technology |
| :--- | :--- |
| Backend | Java 21, Spring Boot 4.1.1, Gradle |
| Database | PostgreSQL 16, Flyway |
| Frontend | React 18, Vite, Axios |
| Testing | JUnit 5, Mockito, AssertJ |
| i18n | Spring MessageSource, i18next (EN / FA) |
| DevOps | Docker, Docker Compose, Git |
